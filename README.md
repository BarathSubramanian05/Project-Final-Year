# Project Tracking System

A full-stack web application for managing projects, tracking progress, and analyzing project performance.

## Features

* Project creation and management
* Track project progress and status
* Employee and project management
* Project analytics and reports
* Dashboard for monitoring projects
* Backend REST APIs
* React-based web interface

## Tech Stack

### Backend

* Java
* Spring Boot
* Spring Data JPA
* Maven

### Frontend

* React
* JavaScript
* Create React App
* HTML
* CSS

### Database

* MySQL

### Other

* Python
* Machine Learning
* REST APIs

## How to Run

### Backend

```bash
cd project-backend
./mvnw spring-boot:run
```

For Windows:

```bash
mvnw.cmd spring-boot:run
```

### Frontend

```bash
cd project-frontend
npm install
npm start
```

The frontend runs at:

```text
http://localhost:3000
```
